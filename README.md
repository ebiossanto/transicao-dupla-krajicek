# Transição Dupla Krajicek

Repositório para o desenvolvimento completo do trabalho que combina pesquisa matemática, projeto de software e arquitetura de sistema.

## Estrutura

- `docs/formalization.md` — Formalização matemática, teoremas e provas.
- `docs/development.md` — Documento de desenvolvimento, design e implementação.
- `docs/tests.md` — Planos de testes e resultados.
- `docs/certificates.md` — Certificados, conformidade e padrões.
- `docs/continuity.md` — Plano de continuidade e próximas etapas.
- `src/` — Código-fonte do produto.
- `tests/` — Testes unitários e de integração.

## Objetivo

Entregar um produto final que integre a base matemática com a implementação de software, devidamente documentado e pronto para continuidade de desenvolvimento.
